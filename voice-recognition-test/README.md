# 掼蛋语音记牌功能测试

这是一个独立的语音识别和指令解析测试项目，用于验证掼蛋语音记牌功能的核心算法。

## 功能特性

- 🎤 **语音识别**: 基于Web Speech API的中文语音识别
- 🧠 **指令解析**: 智能解析掼蛋出牌指令
- 🔧 **容错机制**: 支持同义词和方言处理
- 📝 **实时测试**: 可视化测试界面和结果展示
- ✅ **验证机制**: 指令合法性验证

## 支持的指令格式

### 玩家标识
- `我` - 自己
- `上` - 上家  
- `对` - 对家
- `下` - 下家

### 基本牌型
- **单张**: `我单K`, `上单A`, `对单10`
- **对子**: `我对8`, `上对J`, `下对Q`
- **三张**: `我三7`, `对三A`, `下三10`

### 组合牌型  
- **三带二**: `我三A带5`, `上三8带对2`
- **顺子**: `我顺5五张`, `对顺10三张`
- **炸弹**: `我炸8`, `上5个J`
- **王炸**: `我王炸`, `下王炸`

### 游戏操作
- **过牌**: `我过`, `上过`, `对过`
- **撤销**: `撤销`
- **重置**: `重置`

## 测试说明

### 语音测试
1. 点击"开始录音"按钮
2. 说出指令，如"我单K"
3. 观察识别结果和解析结果

### 文本测试
- 点击底部的测试按钮快速测试各种指令
- 点击指令示例区域的任意示例进行测试

### 测试要点
- **麦克风权限**: 首次使用需要授权麦克风权限
- **网络环境**: 语音识别需要网络连接
- **发音清晰**: 建议普通话发音，语速适中
- **环境安静**: 避免嘈杂环境影响识别准确率

## 核心特性

### 1. 容错机制
- 支持同义词映射（如"勾"="J", "圈"="Q"）
- 自动处理中文数字转换
- 方言和发音差异适配

### 2. 智能解析
- 基于正则表达式的多层解析规则
- 优先级排序，复杂规则优先匹配
- 支持省略词和简化表达

### 3. 验证机制
- 指令格式验证
- 牌面值合法性检查
- 游戏规则基础验证

## 故障排除

### 常见问题

**Q: 浏览器提示不支持语音识别**
A: 请使用Chrome、Edge等支持Web Speech API的浏览器

**Q: 识别准确率低**
A: 
- 检查麦克风是否工作正常
- 确保网络连接稳定
- 尝试标准普通话发音
- 选择安静的环境

**Q: 指令解析失败**
A:
- 参考指令示例，使用标准格式
- 检查玩家标识是否正确
- 确保牌面值有效

**Q: 页面无法访问**
A:
- 确保已运行 `npm run build`
- 检查端口8080是否被占用
- 尝试使用其他端口: `python3 -m http.server 8081 --directory dist`
