🔄 清除缓存工具

适用情况：刷新页面后仍显示旧界面，或者新部署的语音、牌型功能没有生效。

推荐操作：点击“更新程序（保留牌局）”，工具会注销旧 Service Worker 并删除程序缓存，不会清除历史牌局。
手机手动清理方法：
  1. iPhone/iPad Chrome：点击右上角“…” → “删除浏览数据” → 时间范围选“所有时间” → 只勾选“Cookie、网站数据”和“缓存的图片和文件” → 删除。Chrome iOS 没有地址栏锁头按钮，并且会同时清理其他网站数据。
  2. iPhone/iPad Safari：系统“设置” → “App” → “Safari 浏览器” → “高级” → “网站数据”，搜索 pixelforgeai.com.cn，向左滑动删除。
  3. 已添加到主屏幕：先删除旧桌面图标，清理并确认网页更新后，再重新添加。
  4. 电脑：按 Ctrl+Shift+R（Windows/Linux）或 Cmd+Shift+R（Mac）强制刷新。
